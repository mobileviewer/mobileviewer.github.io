How to use the SERP Snippet Preview

  1. Enter your title tag, meta description and page URL. A sample is filled in so you can see how it works.
  2. Switch between Mobile and Desktop to see how Google may display your result.
  3. Watch the counters. Aim to keep the title under about 600 pixels and the description under roughly 155 characters on desktop.
  4. Copy the generated meta tags into the <head> of your page.

How to write a title tag and meta description that get clicks

Search engines show a title, a URL and a description snippet for each result. Google cuts titles by pixel width rather than a fixed character count, which is why a title full of wide letters like W and M gets cut off sooner than one full of narrow letters. This tool measures the width in your browser so the preview is closer to reality than a plain character counter.

Put the main keyword near the front of the title, keep it unique for every page and write it for people first. A meta description does not directly affect ranking, but a clear, accurate one can improve click-through. Google often rewrites snippets to match the query, so treat the preview as a guide rather than a guarantee.

Frequently asked questions

How long should a title tag be?

Google truncates titles by pixel width, commonly around 600 pixels on desktop, which usually fits 50 to 60 characters. Longer titles can still be indexed, but the end may be replaced by an ellipsis in results.

How long should a meta description be?

Aim for roughly 120 to 155 characters. Google may show more or less depending on the query and device, and it sometimes writes its own snippet from the page content.

Is this preview exactly what Google will show?

No. It is an approximation based on typical fonts and limits. Google can change the title, URL display and description at any time, so use the preview to catch obvious truncation.

Do meta descriptions affect rankings?

Google has said meta descriptions are not a direct ranking factor, but they influence how appealing your result looks and therefore how often people click it.
